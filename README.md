# Paṭṭhāna Quest 24 — Android Offline Learning Game

**Native Godot 4.5.1 project**. Contains 24 Myanmar/Pali lessons, 6 worlds, 24 original vector educational illustrations, mini challenge, quizzes, 40 XP per level and local progress save.

**PUBLIC REPOSITORY NOTE:** Original user-uploaded chanting MP3 files and prior third-party illustrative files are NOT included because public redistribution rights have not been verified. This APK is the **media-lite build**, not the prior full audio package. The game works offline but contains no chanting recordings.

## Build APK

Push to `main` or use Actions > Build Paṭṭhāna Quest 24 Android APK > Run workflow. Once successful, download the `Patthana-Quest24-Native-Android-Debug-APK` artifact.

APK build and physical-device verification are distinct steps; consult CI logs. Preview visuals are symbolic teaching illustrations, not literal canonical definitions. The 24 condition list should be reviewed by a qualified Abhidhamma teacher before publication.
