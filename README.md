# Paṭṭhāna Quest 24 — Native Android Learning Game

Godot-based offline learning game for the 24 Paṭṭhāna conditions.

**Repository status:** Public. Only original source and permitted/generated assets will be committed. Third-party MP3 recordings from the prior prototype are **not included** because public redistribution rights are unconfirmed.

The Android APK is built by GitHub Actions. This is a source project; successful compilation and device testing must be verified separately.
